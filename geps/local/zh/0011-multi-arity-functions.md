# GEP-0011: 多参数函数

## 摘要

在 Elixir 中，`get/2` 和 `get/3` 是同一惯用模式：同名但不同参数数量（arity），通常由默认参数（`def get(m, key, default \\ nil)`）产生。Gandora 之前将每个 (名称, 参数数量) 组编译为独立的 Python `def`，因此第二个参数数量会静默地遮蔽第一个。本提案将同一名称的所有子句——跨参数数量——合并为一个生成的 Python 函数，该函数根据参数元组进行分派（元组的长度自然区分了参数数量），并添加了 `\\` 默认参数语法，该语法将脱糖为较短参数数量的委托子句。

## Motivation

标准库不得不避免 `get/2` + `get/3` 风格的 API（GEP-0010 的审查指出了这个缺口），任何粘贴到 Gandora 中的 Elixir 代码库在第一个默认参数上就会崩溃。修复的成本很低，因为子句分派已经匹配整个参数元组：不同长度的元组永远不会冲突，因此多参数性就是现有机制减去一个人为的限制。

## 范围

函数定义（`def`/`defp`）。宏的元数已经共存（它们在展开时通过名称和元数键控）；宏的默认参数被推迟。

## 术语

- **名称组（Name group）**：模块中共享同一函数名的所有 `def`/`defp` 子句，无论其元数如何。
- **默认参数（Default parameter）**：写作 `name \\ expr` 的首部参数。

## 规范

**GEP-0011-R001:** 名称组的所有子句编译为单个生成的 Python 函数。分派按源代码顺序尝试子句；参数元组仅匹配其自身长度的子句，因此不同元数不会相互干扰。此条修正了 GEP-0001-R006 中关于多子句的要点，使其涵盖不同元数。

**GEP-0011-R002:** 头部参数 MAY 带有默认值：`p \\ expr`。默认值 MUST 是尾随的。带有 `k` 个默认值的定义定义了元数 `n-k .. n`：对于每个被省略的后缀，编译器合成一个委托子句，该子句调用该名称并附加缺失的默认值。默认表达式在委托处编译，在调用时从左到右求值，仅在使用时求值。

**GEP-0011-R003:** 在一个名称组内，最多只能有一个定义声明默认值（Elixir 规则）；违反此规则、默认值非尾随、以及在同一组中混用 `def` 和 `defp` 均为编译错误，并指明函数名。

**GEP-0011-R004:** `@doc`/`@example`/`@decorate` 通过其第一个子句附加到名称组，与之前相同（GEP-0007）。无匹配错误 MUST 指明函数及其定义的元数（例如 `no clause of get/2,3 matched`）。引用中指定了元数（如 `&get/3`、`gan doc`）将解析为单个生成的可调用对象。

**GEP-0011-R005:** 生成形态：一个名称组，若其唯一子句仅包含简单变量参数且无默认值，则保持直接的 `def`；任何包含多个子句、模式、守卫或默认值的组，则编译为 `*args` 匹配分派器。确定性（GEP-0001-R024）不变。

## 原理

重用元组分派意味着元数合并不会增加新的运行时形态——
它删除了导致遮蔽的（名称，元数）分区。
将 `\\` 脱糖为委托（而不是 Python 默认值）精确地保持了 Elixir 的语义：默认值可以是每次调用时求值的任意表达式，且每个较短元数都是分派可见的真实子句。

## 向后兼容性

先前被遮蔽的程序（同名，两个参数数量）从静默错误变为正确。`\\` 之前是一个词法错误。没有其他表面变化。

## 安全性和确定性

没有新的评估阶段；委托子句是普通的编译代码。

## 工具与AI使用

代理现在可以逐字移植 Elixir 签名（`def get(m, key, default \\ nil)`），并且应该优先使用默认值，而非手写委托包装器。标准库在 Elixir 已有此类特性之处采用它们（GEP-0010 修订）。

## 被拒绝的替代方案

### Python 默认参数值

`def get(m, key, default=None)` 在导入时求值一次（经典的默认可变参数陷阱），且无法表达特定参数数量的子句；委托机制保留了 Elixir 的语义。

### 按参数数量进行名称修饰（get__2, get__3）

破坏了公共名称契约（GEP-0001-R015）、捕获（`&get/3`）以及 Python 侧的调用者。

## 开放问题

本次修订无。

## 一致性

测试必须涵盖：两个手写参数数量的同一名称的正确调度；默认参数合成所有更短的参数数量（包括调用时求值）；三个R003诊断；组上的文档字符串和装饰器附件；列出参数数量的无匹配消息；以及一个使用默认参数的标准库函数（`Map.get/3`）。
