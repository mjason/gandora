# GEP-0019: 自递归尾调用优化

## 摘要

对尾位置封闭函数的调用会编译为参数重新绑定和循环：

```elixir
def sum_to(0, acc), do: acc
def sum_to(n, acc), do: sum_to(n - 1, acc + n)
```

对于任意 `n` 都在常量栈上运行，而函数体中的 `recur(args)` 是同一跳转的显式、编译器检查的写法（R005）。Elixir 自然的递归风格在 Python 约 1000 帧的限制下变得安全。非尾递归（`n * fact(n - 1)`）则不受影响——它需要自己的栈空间。

## 动机

GEP-0014 为长时间运行的代码提供了 `loop/recur`，因为 Python 没有 TCO，但惯用的 Elixir 是以尾递归方式编写的，如今移植它意味着需要重写每一个这样的函数。自递归尾调用是静态可识别的，并且可以编译为与 `loop` 已经使用的相同的 `while` 形状——自然风格应该直接工作。

## 范围

仅直接自递归。互递归保持调用栈绑定（跳板在 GEP-0014 中被拒绝，并保持拒绝状态）。

## 规范

**GEP-0019-R001:** 一个调用处于尾位置，当且仅当它是以下位置中的最终表达式：子句体、处于尾位置的 `if`/`unless`/`case`/`cond` 分支，或处于尾位置的块。`try` 内部、匿名函数以及参数位置中的表达式永远不会是尾位置。

**GEP-0019-R002:** 如果定义组中的任何子句包含对该组自身名称的尾调用，且该调用的元数与组定义的元数一致，则此组编译为循环：调度（或单个子句体）被包裹在 `while True:` 中，每个尾自调用变成参数元组的重新绑定加上 `continue`。所有其他退出像之前一样 `return`。可观察行为除栈深度外均不变；百万次迭代的自递归 MUST 在测试中通过。

**GEP-0019-R003:** 不在尾位置的自调用编译为普通调用。该优化从不改变求值顺序或参数求值语义；参数在重新绑定前被完全求值。

**GEP-0019-R004:** 该优化同样适用于 `def`、`defp` 以及默认参数委托，并与 `@spec` 注解（GEP-0017）组合而不改变。

**GEP-0019-R005:** 函数体中的 `recur(args)` 是同一跳转的**显式**写法：它重新绑定所在函数的参数并重启函数。它 MUST 处于尾位置，且其元数 MUST 与组中的某个子句匹配——否则两者均为编译错误，这是隐式形式无法给出的保证（将调用移出尾位置的重构只会静默丢失优化；而移动的 `recur` 会破坏构建）。分工：自然的 Elixir 尾递归会被隐式优化以保持可移植性；`recur` 是*断言*恒定栈的写法。

**GEP-0019-R006:** 每个定义组的编译形态是**可观察的**：文档查询在尾递归编译为 `while True:` 重新绑定时报告 `"loop"`，在组仅在非尾位置自递归时报告 `"stack"`，在组不自递归时报告无信息。该形态 MUST 出现在 `gan doc`（本地化文字）、LSP 悬停（徽章行）以及 `gan lsc doc`（`tco` 字段）中——开发者看不见的隐式优化是他们无法信任的隐式优化。在优化循环内部创建的闭包通过 GEP-0021 快照保留每次迭代的值；优化不会因它们而被跳过。

## 动机

重新绑定加 `continue` 正是 `loop/recur` 已有的编译方式；将其扩展到尾部自调用不会增加新的运行时形态，使生成的代码保持可读性（`while True:` + `match`），并使主流的 Elixir 习语原样可移植。互递归被排除，因为它需要要么是蹦床（被拒绝：不透明、较慢），要么是全局程序调用图重写。

## 向后兼容性

保持语义不变；仅栈消耗发生变化。

## 安全性与确定性

除GEP-0001-R024外，无其他要求；输出保持确定性。

## 工具与 AI 使用

代理 SHOULD 为无界迭代编写自然尾递归，当恒定栈是一个值得断言的要求时使用函数级 `recur`，并在迭代是映射而非状态机时使用 `for` (GEP-0020) 或 Enum。

## 被拒绝的替代方案

### 用于相互递归的蹦床

根据 GEP-0014 重新拒绝：隐藏了机制，每次跳转都产生分配成本，且在生成的输出中可读性差。

### 类似 `@tailrec` 的主动标注注解

分析是静态且安全的；要求标注会使得自然的写法在被遗忘时静默地受到栈绑定限制。注解本应承担的断言角色由显式的 `recur`（R005）填补，该关键词是经过检查的而非建议性的。

## 符合性

测试 MUST 涵盖：单子句和多子句尾递归（百万次迭代）；保护子句；`if`/`case`/`cond` 下的尾调用；未优化的非尾自调用（可通过递归限制观察到）；默认值与重新绑定的交互；以及优化前后参考函数的结果一致。
