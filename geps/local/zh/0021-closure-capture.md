# GEP-0021: 闭包捕获语义

## 摘要

Elixir 绑定是不可变的：闭包看到的是其自由变量在闭包创建时的值，后续的重新绑定无法影响到闭包内部。Python lambda 捕捉的是 *变量*，而非值。编译器通过 Python 的惯用方式——默认参数快照（仅限关键字参数，以确保参数数量严格）——来弥合这一差距：

```elixir
x = 1
f = fn -> x end
x = 2
f.()                 # 1，与 Elixir 一致
```

```python
x = 1
f = lambda *, x=x: x
x = 2
f()                  # 1
```

若不如此，尾调用优化（GEP-0019）会放大这一差距，导致错误结果：在 `while` 循环中重新绑定参数会改变所有已逃逸闭包所见的值。

## 动机

下面的 `collect(3, [])` 必须返回闭包，分别绑定 3、2、1 —— 每个迭代都有自己的绑定，这正是真实递归的栈帧所赋予的：

```elixir
def collect(0, acc), do: acc
def collect(n, acc), do: collect(n - 1, [fn -> n end] ++ acc)
```

若编译为使用普通 lambda 的尾递归优化循环，所有闭包将共享同一个重新绑定的 `n`。即使没有尾递归优化，只要变量在闭包捕获后被重新绑定，以及 `for` 推导式的主体中（Python 推导式变量也具有延迟绑定），都会出现同样的分歧。一条规则就能从根源上修复整个问题：捕获时按值捕获，在创建时固定。

## 范围

编译 `fn` 和 `&` 捕获表达式。自由变量分析按封闭函数作用域进行；模块级名称（函数、导入）是稳定的，且不进行快照。

## 规范

**GEP-0021-R001:** 闭包的自由变量，即封闭函数作用域的局部变量（参数、`=`/`<-` 模式绑定、`->` 子句绑定），**在创建时按值捕获**。实现方式：每个这样的名称成为生成的 lambda 或提升的 `def` 上的关键字-only 默认参数 `name=name`。闭包自身绑定的名称——其参数、其体中的赋值（Python 作用域已使其成为局部变量）——不是捕获。模块级名称不是捕获。

**GEP-0021-R002:** 快照 MUST NOT 改变闭包的调用参数数量：它们遵循裸 `*`（`lambda x, *, n=n:`、`def _gan_fn0(*_gan_args, a=a):`），因此额外的位置参数会像之前一样引发 `TypeError`。

**GEP-0021-R003:** 该规则统一适用：单表达式 lambda、提升的多子句 `fn` 定义、`&(...)` 捕获、`for` 推导体中的闭包（快照默认值在每个迭代的推导作用域中求值），以及嵌套闭包（每一层从上一级作用域快照，因此链保持忠实）。

**GEP-0021-R004:** 对于 GEP-0019 循环，快照恢复帧身份：在一次迭代中创建的闭包在后续重新绑定中保持该迭代的值。因此尾调用优化永远不需要跳过，`recur` 保持无限制。

## 理由

各备选方案因改变过多而修复过少被否决。当闭包捕获参数时跳过尾调用优化（TCO）通过放弃常量栈保证来保持语义——这是一种无声的降级，显式的 `recur` 契约无法容忍。对重绑定局部变量进行 SSA 式重命名会使生成的 Python 代码难以辨认。默认参数快照是每位 Python 审查者都熟知的确切针对此问题的惯用方法，每个捕获的名称多花费一个标记，并保持零运行时承诺。

## 向后兼容性

那些其闭包从未观察到重新绑定的程序，在行为上逐字节不变；生成的签名获得仅关键字默认值。而那些确实观察到了重新绑定的程序，与 Elixir 存在分歧——这就是修复。

## 安全性与确定性

除了GEP-0001-R024之外没有其他要求；输出保持确定性。

## 工具与AI使用

Agents SHOULD treat closures as value snapshots (Elixir semantics)  
and MUST NOT rely on Python late-binding behavior through generated code.

## 被否决的备选方案

### 对捕获函数跳过 TCO

安全但静默地受堆栈限制；与 `recur` 的检查性常量堆栈断言 (GEP-0019-R005) 矛盾。

### 对重新绑定的局部变量进行 SSA 重命名

正确且通用，但生成的 Python 代码不再像审阅者会写出的样子。

## 一致性

测试必须覆盖：在直线代码中创建后的重新绑定；闭包逃逸出尾调用优化循环（每次迭代的值）；多子句提升的`fn`；`&`捕获；推导体闭包；嵌套闭包；存在快照时的参数数量严格性；以及未快照的模块级名称。
