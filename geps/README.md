# Gandora Enhancement Proposals

GEPs record Gandora design decisions before implementation. The process is
defined by [GEP-0000](0000-gep-process.md). English sources in this directory
are normative; synchronized non-normative translations live under
[`local/`](local/).

New proposals start from [`template.md`](template.md). The machine-readable
manifest is [`geps.jsonc`](geps.jsonc).
