# GEP — Gandora 增强提案

每一次语言变更都始于一份 GEP — 仓库中一份编号的规范性规范，其模式借鉴了 Python 的 PEP 流程。手册和本网站展示的是语言*如何使用*；GEP 则定义语言*是什么*。英文版本为规范性文本；中文译本并存于 `geps/local/zh/` 目录下。
