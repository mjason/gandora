# GEPs — Gandora Enhancement Proposals

Every language change starts as a GEP — a normative, numbered
specification in the repository, modeled on Python's PEP process.
The manual and this site show *how* to use the language; the GEPs
define *what it is*. English is normative; Chinese translations live
alongside under `geps/local/zh/`.

Browse them on GitHub: **[geps/](https://github.com/mjason/gandora/tree/main/geps)**
